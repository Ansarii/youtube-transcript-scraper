# YouTube Transcript Scraper: Captions, Metadata & Playlists

Get the **transcript of any YouTube video** with timestamps, plus title, channel, publish date, views and length. Give it video links, whole **playlists** or **channels** and it returns one row per video. Choose languages, auto-translate captions, and split transcripts into ready-to-embed chunks for RAG, summaries and AI agents.

Videos without captions, private or unavailable videos are **never charged**. Only delivered transcripts are billed.

## What you get

| Field | Description |
|---|---|
| `status` | `ok`, `no_captions`, `unavailable` or `error` |
| `videoId`, `url`, `title` | Video identity |
| `channelName`, `channelId`, `channelUrl` | Channel |
| `publishDate`, `lengthSeconds`, `viewCount` | Metadata |
| `language`, `isAutoGenerated`, `isTranslation` | Which captions were used |
| `transcript`, `wordCount` | Full transcript text |
| `segments` | `[{ start, duration, text }]` timestamps (optional) |
| `chunks` | `[{ start, end, text }]` fixed-length pieces for embeddings (optional) |
| `availableLanguages` | All caption languages the video offers |

```json
{
  "status": "ok",
  "videoId": "dQw4w9WgXcQ",
  "title": "Rick Astley - Never Gonna Give You Up",
  "channelName": "Rick Astley",
  "language": "en",
  "isAutoGenerated": false,
  "wordCount": 342,
  "transcript": "[Music] We're no strangers to love ...",
  "segments": [{ "start": 18.64, "duration": 3.24, "text": "We're no strangers to love" }]
}
```

(Shortened example.)

## Input

| Field | Default | Notes |
|---|---|---|
| `urls` | required | Video URLs/ids, playlist URLs, channel URLs or `@handles` |
| `languages` | `["en"]` | Preferred languages in order. Manual captions are preferred over auto-generated. If none match, captions are auto-translated into the first language when the video allows it |
| `maxVideosPerSource` | `50` | Limit per playlist or channel |
| `includeSegments` | `true` | Timestamped segments |
| `chunkSeconds` | `0` | Set e.g. `60` to get RAG chunks |
| `includeDescription` | `false` | Adds the video description |

```json
{ "urls": ["https://www.youtube.com/watch?v=dQw4w9WgXcQ", "@mkbhd"], "languages": ["en", "es"], "maxVideosPerSource": 20, "chunkSeconds": 60 }
```

## Why it is reliable

YouTube blocks most automated traffic from data-center IPs. This Actor routes through residential proxies by default, rotates the IP and retries on bot checks and rate limits, and reports a clear status per video instead of silently skipping it.

## Limits

- Only videos that have captions (written or auto-generated) can return a transcript. Auto-generated captions can contain errors.
- Private, deleted, age-restricted or members-only videos return `unavailable`.
- Live streams without captions yet return `no_captions`.
- Very large channels are capped by `maxVideosPerSource`.
- Respect YouTube's terms and the rights of content owners when using transcripts.

## FAQ

**Can I get transcripts for a whole channel?** Yes. Pass the channel URL or @handle and set `maxVideosPerSource`.

**Can I get a language the video does not offer?** If the video allows translation, captions are auto-translated into your first preferred language and marked `isTranslation: true`.

**How do I use it with an AI agent or RAG pipeline?** Set `chunkSeconds` and embed the `chunks`, or pass `transcript` directly to your LLM. The Actor can also be called over MCP through Apify.

**Something broke?** Open an issue from the Issues tab with the run URL and the video link.
